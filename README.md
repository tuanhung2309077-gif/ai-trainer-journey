# Hành trình AI Trainer — 3 tháng

> Repo học tập công khai của Tuấn Hưng: toàn bộ quá trình trở thành **AI trainer kỹ thuật cho tiếng Việt** — vừa học vừa làm vừa thí nghiệm, mọi hiện vật đều ở đây.
> Lộ trình chi tiết: xem file `lo-trinh-3-thang-ai-trainer.md` (bản 4.0).

## Mục tiêu

- Trở thành AI trainer freelance: gán nhãn dữ liệu tiếng Việt, đánh giá phản hồi mô hình, thiết kế rubric, viết prompt đánh giá.
- Mỗi tuần ra hiện vật thật bỏ vào `portfolio/` — repo này chính là bằng chứng năng lực cho khách hàng.

## Cấu trúc

```
tuan-01/ ... tuan-12/   mỗi tuần: TUAN.md (nhật ký) + file bài làm
portfolio/              mẫu eval đẹp nhất (text, voice, safety)
scripts/                script Python (tính % đồng thuận...)
mau-tuan.md             template nhật ký tuần
```

## Quy tắc

1. **NDA:** không bao giờ đẩy dữ liệu job thật lên đây — chỉ mẫu tự tạo hoặc ẩn danh.
2. **Trung thực:** chỉ ghi vào profile Upwork những skill đã luyện xong ở đây.
3. **Mock test:** không dùng AI, không tra cứu, bấm giờ thật; điểm mock không dự đoán điểm thi thật.
4. Mỗi tuần cập nhật checkbox tiến độ ở trên.
